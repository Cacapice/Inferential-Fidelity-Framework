# results/

Every file here is regenerated by a script in `scripts/`; none is hand-edited.
Re-running the script overwrites the corresponding outputs, so a mismatch
between a figure and the current code is a bug.

| file | produced by | contents |
|---|---|---|
| `pilot.json`, `pilot.png` | `run_pilot.py` | headline table: identity, reduced-transfer and constructed controls against the frozen gate |
| `scaling.json`, `scaling.png` | `run_scaling.py` | Krylov-vs-dense validation, truncation and volume convergence |
| `neural.json`, `neural.png` | `run_learned.py` | VMC neural quantum state and the POD/Galerkin rank sweep |
| `feasibility.json`, `feasibility.png` | `run_feasibility.py` | detection and undetected intervals, ρ\*, window sweep, discretisation stability |
| `modulus.json`, `non_equivalence.png` | `run_modulus.py` | ω(ε), the gated modulus, and the non-equivalence diagram |
| `inferential_fidelity.png`, `benchmark_logic.png` | `make_unifying_figure.py`, `make_logic_figure.py` | schematic figures used in the README |

The scripts `run_graph_instance.py`, `run_sketch_nullspace_instance.py`, and
`run_pde_flux_instance.py` print their results and write no files. They cover,
respectively, the graph reference application, the exact sketch-nullspace theorem
instance, and the POD hot-spot certified-floor instance.

**Provenance.** Numerical values quoted in `README.md`, `methods.md`,
and `RELEASE_MANIFEST.md` belong to the named instance or theorem demonstration, not to
the domain-independent theory. Coverage status must be read with each result: Tier
1 values are exact, Tier 2 values are certified adversarial floors, and Tier 3
values are exploratory samples.
